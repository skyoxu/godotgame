# 项目资源知识目录

`docs/knowledge/**` 保存可人工审阅的项目资源知识：配置、素材、场景、代码、测试及其关系。

- 本目录不是 Taskmaster、PRD/GDD、ADR、Overlay、Contracts 或源码的替代 SSoT。
- `catalog/**` 保存人工可审阅条目；模板默认为空。
- `generated/**` 保存可再生成的关系；模板默认为空。
- `indexes/**` 保存目录版本指针，不保存 Knowledge Control Plane 的发布权威状态。
- `logs/**` 只保存运行证据，不作为生产知识事实来源。
- Chapter 6 可在真实任务存在后补充关系；不得把推断关系标为 confirmed。
